# Resume Uploads

Place your resume PDF files in this folder, then update the links in `README.md`.

## Suggested naming convention

| File name | Purpose |
|---|---|
| `resume_general.pdf` | General Software Engineer resume |
| `resume_ml.pdf` | Machine Learning / Data Science focused |
| `resume_cv.pdf` | Computer Vision focused |
| `resume_swe.pdf` | Backend / Systems Engineering focused |

> **Note:** After uploading, update the resume table in `README.md` with the correct relative links.
